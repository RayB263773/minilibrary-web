Mini Library

Личный каталог книг на C++ и PostgreSQL

Книг: 0

    О веб-приложении Mini Library

    Клиент-серверное приложение для управления личной библиотекой и чтения книг онлайн. Серверная часть написана на C++20 с использованием микрофреймворка Crow и хранит данные в СУБД PostgreSQL.

    Технологический стек

    • Backend: C++20, Crow HTTP Framework
    • База данных: PostgreSQL + драйвер libpqxx
    • Frontend: HTML5, CSS3, Vanilla JS (Fetch API)

    Модульная архитектура

    Логика разделена на независимые слои: HTTP-маршруты и упаковка JSON находятся в main.cpp, а параметризованные SQL-запросы изолированы в модуле books.h / books.cpp.

    Маршруты REST API

    • GET /api/books — список всех книг с текстом
    • GET /api/books?q=... — поиск по названию и автору
    • POST /api/books — добавление книги и текста
    • DELETE /api/books/<id> — удаление по ID

    Надежность и защита

    Конфигурация подключения к БД передается через переменную окружения DATABASE_URL, а все пользовательские параметры проходят через pqxx::params для защиты от SQL-инъекций.
