    О веб-приложении Mini Library

    Клиент-серверное приложение с полным циклом операций CRUD для управления личной библиотекой и комфортного чтения книг онлайн. Серверная часть написана на C++20 с использованием микрофреймворка Crow и СУБД PostgreSQL.

    Технологический стек

    • Backend: C++20, Crow HTTP Framework
    • База данных: PostgreSQL + драйвер libpqxx
    • Frontend: HTML5, CSS3, Vanilla JS (Fetch + FileReader)

    Умная читалка без скролла

    Текст книги индексируется по смещениям символов без дублирования памяти и верстается строго под высоту окна с поддержкой настройки шрифта и перелистывания колесом мыши.

    Маршруты REST API (CRUD)

    • GET /api/books — список и поиск книг
    • GET /api/books/<id> — подгрузка текста книги
    • POST /api/books — добавление книги и .txt
    • PUT /api/books/<id> — редактирование книги
    • DELETE /api/books/<id> — удаление по ID

    Надежность и защита

    Конфигурация подключения к БД передается через переменную окружения DATABASE_URL, а все пользовательские параметры проходят через pqxx::params для защиты от SQL-инъекций.
