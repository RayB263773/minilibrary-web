    О веб-приложении Mini Library

    Клиент-серверное приложение для управления личной библиотекой и постраничного чтения книг онлайн. Серверная часть написана на C++20 с использованием микрофреймворка Crow и хранит данные в СУБД PostgreSQL.

    Технологический стек

    • Backend: C++20, Crow HTTP Framework
    • База данных: PostgreSQL + драйвер libpqxx
    • Frontend: HTML5, CSS3, Vanilla JS (Fetch + FileReader)

    Оптимизированная загрузка

    Каталог загружает только легкие метаданные книг, а полный текст запрашивается отдельно по маршруту GET /api/books/<id> и разбивается на страницы без нагрузки на браузер.

    Маршруты REST API

    • GET /api/books — метаданные всех книг
    • GET /api/books/<id> — подгрузка текста книги
    • POST /api/books — загрузка книги и .txt
    • DELETE /api/books/<id> — удаление по ID

    Надежность и защита

    Конфигурация подключения к БД передается через переменную окружения DATABASE_URL, а все пользовательские параметры проходят через pqxx::params для защиты от SQL-инъекций.
