    О ПРОЕКТЕ

    MiniLibrary — пространство для чтения

    Клиент-серверное приложение с полным циклом операций CRUD для управления личной библиотекой и комфортного чтения книг онлайн. Серверная часть написана на C++20 с использованием Crow и PostgreSQL.

    Технологический стек

    • Backend: C++20, Crow HTTP Framework
    • База данных: PostgreSQL + libpqxx
    • Frontend: HTML5, CSS3, Vanilla JS

    Умная читалка без скролла

    Текст книги индексируется по смещениям символов без дублирования памяти и верстается строго под высоту окна. Есть настройка шрифта и перелистывание страниц.

    Маршруты REST API

    • GET /api/books — список и поиск
    • GET /api/books/<id> — текст книги
    • POST /api/books — добавление
    • PUT /api/books/<id> — редактирование
    • DELETE /api/books/<id> — удаление

    Надёжность и защита

    Подключение к БД задаётся через DATABASE_URL, пользовательские параметры SQL передаются через параметризованные запросы.
